# Bibliothèques tierces

Le fichier `public/vendor/qrcode.mjs` provient de **qrcode-generator 2.0.4**, de Kazuhiko Arase, sous licence MIT. Les mentions de copyright et de licence sont conservées dans le fichier. Source : https://github.com/kazuhikoarase/qrcode-generator.

**jsQR 1.4.0**, sous licence Apache-2.0, est utilisé uniquement dans les tests pour décoder les QR codes générés. Source : https://github.com/cozmo/jsQR.
